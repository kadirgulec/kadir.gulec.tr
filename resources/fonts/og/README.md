# Fonts for Open Graph images

TTF copies of the site's fonts (latin + latin-ext, for Turkish), used only on
the server by `App\Support\Og\OgImage` to draw link preview images. The site
itself loads its fonts through Vite (`vite.config.js`).

Fraunces, Nunito Sans and Caveat are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). Downloaded from Google Fonts via
google-webfonts-helper.
